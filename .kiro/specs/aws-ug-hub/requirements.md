# Requirements Document

## Introduction

The full requirements for aws-ug-hub are in the [steering requirements](../../steering/requirements.md) #[[file:.kiro/steering/requirements.md]]. That file is the single source. It holds the goals, users, glossary, R1 to R24, N1 to N8, out of scope items and decisions. R17 to R24 and N8 were added on 2026-11-07.

This spec refers to the requirements by ID only. It does not repeat their text. Design and tasks cite the same IDs. The running heading number is needed by the spec format. The ID after it is the one to cite.

Each entry below gives the ID, the title and the area of the spec that covers it. The areas are events, photos, configuration, access, public site, phone experience and non-functional. Each entry has one acceptance criterion for every criterion of the [steering requirement](../../steering/requirements.md), in the same order. A criterion ID is the requirement ID, a dot and the criterion number, for example R10.1 or N4.2.

## Glossary

- **System**: The aws-ug-hub site. All other terms are defined in the Glossary of the [steering requirements](../../steering/requirements.md) (#[[file:.kiro/steering/requirements.md]]).
